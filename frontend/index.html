Thermal Image Restoration via Deep Image Prior

Reconstruct damaged long-wave infrared (LWIR) captures, inpaint dead microbolometer sensor pixels, and suppress thermal noise using the structural inductive bias of a 5-level U-Net generator.

Open Restoration Studio → Explore U-Net Architecture & Math

Zero Dataset Dependence

Unlike conventional deep learning methods that require paired datasets of clean and damaged thermal pairs, DIP optimizes exclusively on the single degraded test image at test time.

5-Level U-Net Generator

Features progressive channel capacity (16 → 32 → 64 → 128 → 128) with 1×1 skip projections reducing channels to 4, preserving sharp thermal gradients without passing noise.

Microbolometer Sensor Inpainting

Targeted masked loss computation isolates dead detector pixels and readout streak artifacts, synthesizing natural thermal diffusion without spatial blurring artifacts.

Optimized for Google Colab GPU Execution

The computational backbone runs with full CUDA acceleration on Google Colab T4/V100 GPUs, seamlessly communicating with this web client via an encrypted HTTPS tunnel.
